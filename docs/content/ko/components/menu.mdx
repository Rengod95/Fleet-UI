### (A) 한줄 요약

**`Menu`는 트리거(버튼 등)를 눌러 드롭다운을 표시하고, 항목 선택/체크를 제공하는 합성(Compound) 컴포넌트예요.**  
`Menu.Trigger`가 열림 상태(controlled/uncontrolled), 바깥 클릭 닫힘, 선택 시 닫힘을 관리하고, `Menu.Dropdown/DropdownItem/DropdownCheckItem`이 메뉴 UI를 구성해요.

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 가장 흔한 사용 시나리오(최소 예제)

```tsx title="Menu basic usage"
import { Menu, Button } from '@fleet-ui/components';

export function Example() {
  return (
    <Menu.Trigger
      dropdown={
        <Menu.Dropdown header={<Menu.Header>정렬</Menu.Header>}>
          <Menu.DropdownItem onPress={() => {}}>최신순</Menu.DropdownItem>
          <Menu.DropdownItem onPress={() => {}}>인기순</Menu.DropdownItem>
        </Menu.Dropdown>
      }
    >
      <Button>메뉴 열기</Button>
    </Menu.Trigger>
  );
}
```

#### D-2. CheckItem: `Menu.DropdownCheckItem`

`DropdownCheckItem`은 내부적으로 `checked` 상태를 토글하고 `onCheckedChange(next)`를 호출해요.  
또한 `closeOnSelect=true`이면 체크 후 메뉴가 닫혀요.

```tsx title="Menu check items"
import { useState } from 'react';
import { Menu, Button } from '@fleet-ui/components';

export function Example() {
  const [checked, setChecked] = useState(false);

  return (
    <Menu.Trigger
      dropdown={
        <Menu.Dropdown>
          <Menu.DropdownCheckItem checked={checked} onCheckedChange={setChecked}>
            옵션 A
          </Menu.DropdownCheckItem>
        </Menu.Dropdown>
      }
    >
      <Button>옵션</Button>
    </Menu.Trigger>
  );
}
```

#### D-3. 닫힘 정책

- `closeOnOutsidePress`: 오버레이(바깥 영역) 누르면 닫기 (기본 true)
- `closeOnSelect`: 항목 선택 시 닫기 (기본 true)

메뉴가 “설정 토글”처럼 여러 개 연속으로 체크해야 하는 UX라면, `closeOnSelect={false}`를 고려해요.

### (E) 내부 상태 / Shared Value / Animation (필수)

#### E-1. 상태 모델(Trigger)

`Menu.Trigger`는 controlled/uncontrolled를 모두 지원해요.

- controlled: `open`이 있으면 `isOpen = open`
- uncontrolled: `defaultOpen`으로 내부 상태를 시작하고, 내부에서 `setInternalOpen`으로 토글

또한 닫힘 애니메이션이 끝날 때까지 `Modal`을 유지하기 위해 `modalVisible`이라는 별도 상태를 둬요.

#### E-2. Reanimated / Shared Value

드롭다운 표시 애니메이션은 다음 shared value로 처리해요.

- `opacity`: 0 → 1 (open), 1 → 0 (close)
- `scaleX/scaleY`: 0 → 1로 전환(딜레이 포함)

닫힘 시에는 애니메이션 완료 콜백에서 모달을 숨겨요.

### (F) 접근성(누락 금지)

- 드롭다운 컨테이너: `accessibilityRole="menu"` (`Menu.Dropdown`)
- 메뉴 아이템: `accessibilityRole="menuitem"` (`Menu.DropdownItem/DropdownCheckItem`)
- Trigger 모달 스코프:
  - `accessibilityViewIsModal`
  - `importantForAccessibility="yes"`
  - `onAccessibilityEscape`로 닫기 지원

권장 규칙:
- 아이템 텍스트가 문자열이면 자동으로 라벨로 사용되지만, 커스텀 children을 쓰는 경우 `accessibilityLabel`을 제공해요.
