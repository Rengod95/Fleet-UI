### (A) 한줄 요약

**`StepIndicator`는 여러 단계 중 현재 위치를 “점(dot) 스트립”으로 표시하는 컴포넌트예요.**  
`activeStep`(0-based)로 현재 단계를 표시하고, `interactive=true`이면 사용자가 특정 점을 탭해 단계 이동을 트리거할 수 있어요.

---

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 기본 사용

```tsx title="StepIndicator basic usage"
import { StepIndicator } from '@fleet-ui/components';

export function Example() {
  return <StepIndicator step={5} activeStep={2} />;
}
```

#### D-2. Interactive 모드

```tsx title="Interactive"
import { useState } from 'react';
import { StepIndicator } from '@fleet-ui/components';

export function Example() {
  const [active, setActive] = useState(0);

  return (
    <StepIndicator
      step={5}
      activeStep={active}
      interactive
      onStepChange={setActive}
      onStepPress={(i) => console.log('pressed', i)}
    />
  );
}
```

### (E) 내부 상태 / Shared Value / Animation (필수)

#### E-1. 상태 모델

- `step`은 1~100 범위로 clamp돼요.
- `activeStep`은 0~(step-1) 범위로 clamp돼요.
- controlled/uncontrolled:
  - controlled: `activeStep` 제공 시
  - uncontrolled: `defaultActiveStep`로 내부 상태를 시작하고, interactive에서 내부 상태를 갱신

#### E-2. Reanimated / Shared Value

- `activeStepSV`(`SharedValue<number>`)를 사용해 현재 단계를 애니메이션으로 동기화해요.
- 각 dot은 derived value로:
  - `isActive`: 현재 step인지
  - `isCompleted`: 현재보다 이전 step인지
  를 계산해요.
- 활성 dot은 폭이 늘어나고(“pill”처럼), fill opacity가 활성/완료 상태에서 1로 전환돼요.

---

### (F) 접근성(누락 금지)

- 루트: `accessibilityRole="progressbar"`
- `accessibilityValue: { min: 0, max: step-1, now: activeStep }`
- `accessibilityLabel` 기본값: `Step {activeStep+1} of {step}`

interactive일 때:
- 각 점은 `accessibilityRole="button"`이며, `accessibilityState.selected`로 현재 선택 상태를 전달해요.
