### (A) 한줄 요약

**`ContextHeader`는 모바일 화면에서 네이티브 네비게이션 헤더를 대체할 수 있는 커스텀 헤더 컴포넌트예요.**  
좌측(뒤로/커스텀), 중앙(타이틀), 우측(액션) 3영역 구조를 제공하고, 안전영역 포함/고정 배치(fixed) 같은 화면 레이아웃 옵션을 지원해요.

---

### (B) 설치 방법 (Track A / Track B)

#### Track A (CLI / local install)

1) **ContextHeader 추가**

```bash title="Track A: add ContextHeader"
pnpm dlx @fleet-ui/cli add ContextHeader
```

2) **import 예시**

```ts title="Track A: import"
import { ContextHeader } from '@fleet-ui/local/components';
```

#### Track B (NPM package)

1) **import 예시**

```ts title="Track B: import"
import { ContextHeader } from '@fleet-ui/components';
```

#### (필수) 컴포넌트별 추가 의존성

기본 뒤로 버튼 아이콘을 쓰려면 `lucide-react-native`가 필요해요.

```bash title="Recommended runtime deps"
pnpm add lucide-react-native react-native-unistyles
```

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 가장 흔한 사용 시나리오(최소 예제)

```tsx title="ContextHeader basic usage"
import { ContextHeader } from '@fleet-ui/components';

export function Example() {
  return <ContextHeader title="상세" onBackPress={() => {}} />;
}
```

#### D-2. 좌측 영역: `left` vs 기본 BackButton

- `left`가 제공되면 **기본 BackButton을 대체**한다.
- `left`가 없고 `showBackButton=true`이면 기본 BackButton이 표시돼요.
- 기본 BackButton을 누르면 `onBackPress()`가 호출돼요.

```tsx title="Custom left / right"
import { ContextHeader, IconButton } from '@fleet-ui/components';
import { X } from 'lucide-react-native';

export function Example() {
  return (
    <ContextHeader
      title="프로필"
      left={<IconButton aria-label="닫기" icon={<X />} onPress={() => {}} />}
      right={<IconButton aria-label="편집" icon={<X />} onPress={() => {}} />}
      showBackButton={false}
    />
  );
}
```

#### D-3. 타이틀 정렬: `titleAlign` 자동 규칙

`titleAlign`을 지정하지 않으면 구현에서 다음과 같이 자동으로 결정해요.

- 좌측 콘텐츠가 존재하면(=`left`가 있거나 `showBackButton=true`) 기본은 `'center'`
- 좌측 콘텐츠가 없으면 기본은 `'left'`

이는 “좌측이 비어있는데 타이틀을 중앙으로 강제하면 어색한 레이아웃”이 되는 걸 방지하기 위한 규칙이에요.

#### D-4. 안전영역/고정 배치

- `includeSafeAreaTop=true`: 상단 safe area inset만큼 paddingTop을 추가해요.
- `fixed=true`: 헤더를 `position: 'absolute'`로 상단에 고정해요.

> 주의: `fixed=true`를 사용하면 본문 콘텐츠가 헤더 뒤로 들어갈 수 있으므로, 스크린 컨테이너에서 상단 패딩/마진을 별도로 확보하는 게 일반적이에요.

---

### (E) 내부 상태 / Shared Value / Animation (필수)

`ContextHeader`는 내부 상태/애니메이션(shared value)을 갖지 않아요.  
대신 다음 “레이아웃 정책”을 내부에서 결정해요.

- `hasLeftContent = left !== undefined || showBackButton`
- `titleAlign` 기본값을 `hasLeftContent`에 따라 자동 결정
- `titleAlign='center'`일 때 타이틀은 absolute positioning으로 중앙 정렬(pointerEvents=\"none\")

---

### (F) 접근성(누락 금지)

- 타이틀 텍스트는 `accessibilityRole="header"`로 렌더링돼요.
- 기본 BackButton은:
  - `accessibilityRole="button"`
  - `accessibilityLabel="뒤로 가기"`

권장 규칙:
- `left/right`에 아이콘-only 버튼을 넣는 경우, 해당 버튼에 `aria-label`/`accessibilityLabel`을 제공해요.
