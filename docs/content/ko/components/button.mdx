### (A) 한줄 요약

`Button`은 사용자 액션을 트리거하는 기본 인터랙션 컴포넌트예요. `leftIcon / rightIcon`, `loading`, `fullWidth` 같은 **기능/상태 중심 props(속성)**를 안전하게 조합할 수 있게 설계됐어요.

---

### (B) 설치 방법 (Track A / Track B)

#### Track A (CLI / local install)

1) **Button 추가**

```bash title="Track A: add Button"
pnpm dlx @fleet-ui/cli add Button
```

2) **import 예시**

```ts title="Track A: import"
import { Button } from '@fleet-ui/local/components';
```

#### Track B (NPM package)

1) **import 예시**

```ts title="Track B: import"
import { Button } from '@fleet-ui/components';
```

#### (필수) 컴포넌트별 추가 의존성

`Button`은 press 인터랙션 애니메이션을 위해 Reanimated가 필요해요.

```bash title="Recommended runtime deps"
# Expo라면 npx expo install 사용을 권장
pnpm add react-native-reanimated react-native-gesture-handler react-native-unistyles
```

> `Button` 자체는 `expo-blur`/`expo-image`/`expo-linear-gradient` 같은 Expo 모듈을 요구하지 않아요.

### (D) 핵심 기능(컴포넌트별) & 사용법

### 1) 기본 사용

```tsx title="Basic"
import { Button } from '@fleet-ui/components';

export function Example() {
  return <Button onPress={() => console.log('pressed')}>계속하기</Button>;
}
```

#### 2) 아이콘 슬롯: `leftIcon` / `rightIcon`

- 텍스트 버튼에 아이콘을 붙여 “의미/방향”을 더 분명하게 만들 때 써요.
- `loading=true`면 **leftIcon 영역은 로더로 대체**돼요.

```tsx title="Left / Right Icon"
import { Button } from '@fleet-ui/components';
import { View } from 'react-native';

function DemoIcon() {
  return <View style={{ width: 16, height: 16 }} />;
}

export function Example() {
  return (
    <>
      <Button leftIcon={<DemoIcon />}>뒤로</Button>
      <Button rightIcon={<DemoIcon />}>다음</Button>
    </>
  );
}
```

#### 3) 로딩: `loading` (중요)

`loading=true`면:

- 클릭이 막혀요(disabled 처리)
- left 영역에 `ActivityIndicator`가 표시돼요
- 접근성 상태에서 `busy: true`로 전달돼요

```tsx title="Loading"
import { Button } from '@fleet-ui/components';

export function Example() {
  return <Button loading>저장하는 중...</Button>;
}
```

#### 4) 전체 너비: `fullWidth`

```tsx title="Full Width"
import { Button } from '@fleet-ui/components';
import { View } from 'react-native';

export function Example() {
  return (
    <View style={{ gap: 12 }}>
      <Button fullWidth>계속하기</Button>
      <Button fullWidth variant="ghost">나중에 할게요</Button>
    </View>
  );
}
```

### (E) 내부 상태 / Shared Value / Animation

`Button`은 “press” 인터랙션을 **Reanimated shared value**로 처리해요.

### 상태 모델

- 외부 입력: `disabled`, `loading`
- 내부 파생 상태:
  - `isDisabled = Boolean(disabled || loading)`
  - `accessibilityState = { disabled: isDisabled, busy: loading }`

즉, `loading=true`는 로더만 보여주는 게 아니라 **상호작용(press)을 막는 상태**예요.

### Shared Value 흐름(개념)

- `scale` / `opacity` shared value가 press-in/out에서 바뀌어요.
- press-in:
  - `scale = 0.94` / `opacity = 0.86`로 스프링 애니메이션
- press-out:
  - `scale = 1` / `opacity = 1`로 복귀
- disabled(또는 loading) 상태에서는 press-in을 무시하고, `opacity`를 추가로 낮춰요.

> 팁: 바깥에서 scale 애니메이션을 또 적용하면 press 애니메이션과 곱해져 과하게 작아질 수 있어요. 이런 경우 `shadow="none"`으로 두고 애니메이션을 한쪽으로 통일하거나, Button을 감싸는 외부 애니메이션을 최소화하는 걸 권장해요.

---

### (F) 접근성(누락 금지)

- 기본 role: `accessibilityRole="button"`
- 라벨 결정 우선순위:
  - `aria-label` → `accessibilityLabel`(PressableProps) → `children`(문자열인 경우)
- 상태 전달:
  - `accessibilityState: { disabled, busy }`

### 아이콘-only 버튼(권장 규칙)

아이콘만 렌더링하는 경우, 스크린리더/웹을 위해 `aria-label`을 제공하는 걸 권장해요.

```tsx title="Icon-only a11y"
import { Button } from '@fleet-ui/components';

export function Example() {
  return (
    <Button aria-label="즐겨찾기" onPress={() => {}}>
      ★
    </Button>
  );
}
```

| `size` | `'sm' \| 'md' \| 'lg' \| 'xl'` | No | `'md'` | 크기/밀도 | 범용 스타일은 Playground로 확인 |
| `shadow` | `'none' \| 'sm' \| 'md' \| 'lg'` | No | `'none'` | 그림자 프리셋 | 범용 스타일은 Playground로 확인 |

### PressableProps 상속(공통)

`ButtonProps`는 `PressableProps`를 상속해요(단, `children`, `style`은 Button에서 재정의해요).

자주 쓰는 예:

| Prop | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `onPress` | `(event) => void` | No | - | 클릭/탭 핸들러 |
| `onPressIn` | `(event) => void` | No | - | press 시작 |
| `onPressOut` | `(event) => void` | No | - | press 종료 |
| `disabled` | `boolean` | No | - | 비활성(단, `loading=true`면 내부적으로도 비활성 처리) |
| `accessibilityLabel` | `string` | No | - | 접근성 라벨(aria-label 다음 우선) |

> 나머지 `PressableProps`도 그대로 지원해요. (RN/Expo 버전에 따라 세부 props는 달라질 수 있어요)
