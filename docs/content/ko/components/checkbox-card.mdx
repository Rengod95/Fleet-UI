### (A) 한줄 요약

**`CheckboxCard`는 “카드 전체가 체크박스처럼 동작”하는 선택 UI예요.**  
단일 카드에서는 `checked/defaultChecked/onCheckedChange`로 동작하고, 그룹에서는 `CheckboxCardGroup` 컨텍스트를 통해 `value` 기반으로 다중 선택을 관리해요.

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 가장 흔한 사용 시나리오(최소 예제: 단일)

```tsx title="CheckboxCard (uncontrolled)"
import { CheckboxCard } from '@fleet-ui/components';

export function Example() {
  return (
    <CheckboxCard
      title="배송지 기본값으로 저장"
      description="다음 주문에서 기본 배송지로 사용합니다."
      defaultChecked={false}
      onCheckedChange={(checked) => console.log({ checked })}
    />
  );
}
```

#### D-2. 그룹 사용: `CheckboxCardGroup` + `value`

그룹에서는 각 카드가 `value`로 식별되고, 그룹이 `values/defaultValues/onValuesChange`로 다중 선택을 관리해요.

```tsx title="CheckboxCardGroup (controlled)"
import { useState } from 'react';
import { CheckboxCard, CheckboxCardGroup } from '@fleet-ui/components';

export function Example() {
  const [values, setValues] = useState<string[]>(['a']);

  return (
    <CheckboxCardGroup
      values={values}
      onValuesChange={setValues}
      min={0}
      max={2}
      gap="md"
    >
      <CheckboxCard value="a" title="A 옵션" description="설명" />
      <CheckboxCard value="b" title="B 옵션" description="설명" />
      <CheckboxCard value="c" title="C 옵션" description="설명" />
    </CheckboxCardGroup>
  );
}
```

#### D-3. 선택 상태에 따른 스타일 변경(Selected props)

`CheckboxCard`는 선택 상태에서 시각적 강조를 주기 위해 다음을 제공해요.

- `selectedColorScheme`: 선택 시 colorScheme 변경
- `selectedVariant`: 선택 시 카드 variant 변경
- `indicatorSelectedVariant`: 선택 시 체크박스 indicator variant 변경

### (E) 내부 상태 / Shared Value / Animation (필수)

#### E-1. 상태 모델(우선순위: Group > Controlled > Uncontrolled)

구현상 체크 상태 결정 우선순위는 아래와 같아요.

1) **Group + value 제공 시**: 그룹 컨텍스트(`isSelected(value)`)를 사용  
2) **그 외** `checked`가 있으면: controlled  
3) 둘 다 아니면: `defaultChecked` 기반 uncontrolled 내부 상태

또한 disabled는 다음을 합친 값이에요.

- 카드 자체 `disabled`
- 그룹 `disabled`
- 그룹 사용 시: `max`에 도달했고 현재 카드가 미선택이면(= 추가 선택 불가) disabled 처리

#### E-2. Reanimated / Shared Value

카드 press 인터랙션과 컬러 전환을 위해 shared value를 써요.

- press-in: `scale`을 0.96으로, `opacity`를 0.7로 스프링 애니메이션
- press-out: `scale/opacity`를 1로 복귀
- 선택 상태 전환 시: background/border 색상을 애니메이션 스프링으로 전환

> 주의: 내부에서 opacity 애니메이션을 사용하므로, 외부에서 추가 opacity/scale 애니메이션을 중첩하면 기대와 다르게 보일 수 있다.
> 주의: 내부에서 opacity 애니메이션을 사용하므로, 외부에서 추가 opacity/scale 애니메이션을 중첩하면 기대와 다르게 보일 수 있어요.

### (F) 접근성(누락 금지)

`CheckboxCard`는 카드 전체를 체크박스로 취급해요.

- 기본 role: `accessibilityRole="checkbox"`
- 라벨: `accessibilityLabel || title`
- 상태 전달: `accessibilityState: { checked, disabled }`

권장 규칙:
- `title`이 화면에 보이지 않는 커스텀 헤더/슬롯 구성을 하면, `accessibilityLabel`을 명시하는 걸 권장해요.
