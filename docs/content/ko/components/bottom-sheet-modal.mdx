### (A) 한줄 요약

**`BottomSheetModal`은 화면 하단에서 올라오는 모달(바텀 시트)을 제공하는 합성(Compound) 컴포넌트예요.**  
루트는 `visible`로 노출 상태를 제어하고, 내부 서브컴포넌트(`Header/Body/BodyDescription/Action/Footer`)로 레이아웃을 구성해요.

---

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 가장 흔한 사용 시나리오(최소 예제)

```tsx title="BottomSheetModal basic usage"
import { useState } from 'react';
import { View, Text } from 'react-native';
import { BottomSheetModal, Button } from '@fleet-ui/components';

export function Example() {
  const [open, setOpen] = useState(false);

  return (
    <View>
      <Button onPress={() => setOpen(true)}>바텀 시트 열기</Button>

      <BottomSheetModal
        visible={open}
        onDismiss={() => setOpen(false)}
        size="lg"
        detached
      >
        <BottomSheetModal.Header title="제목" subtitle="설명" />
        <BottomSheetModal.Body>
          <Text>콘텐츠 영역</Text>
        </BottomSheetModal.Body>
        <BottomSheetModal.Action
          layout="horizontal"
          showPrimary
          showSecondary
          primaryButtonProps={{ children: '확인' }}
          secondaryButtonProps={{ children: '취소' }}
        />
      </BottomSheetModal>
    </View>
  );
}
```

#### D-2. `visible` + `onDismiss`: 외부 제어 모델(중요)

`BottomSheetModal`은 루트에서 `visible`로 노출 여부를 제어해요.

- `visible=true`가 되면 내부에서 `present()`가 호출돼요.
- `visible=false`가 되면 내부에서 dismiss를 시도해요.
- `onDismiss`에서는 **상태를 false로 내려야** 해요.

> 주의: `onDismiss`는 “닫힘 이벤트 통지”라기보다, 타입/주석 기준으로 **호출되어야 모달이 정상 해제되는 계약**에 가까워요. 그래서 `visible`과 `onDismiss`를 한 쌍으로 운영해야 해요.

#### D-3. 합성(Compound) 서브컴포넌트

`BottomSheetModal`은 아래 서브컴포넌트를 제공해요.

- `BottomSheetModal.Header`: `title/subtitle/actionIcon` 또는 `children`로 헤더 구성
- `BottomSheetModal.Body`: 본문 컨테이너(패딩/사이즈 프리셋)
- `BottomSheetModal.BodyDescription`: 중앙 정렬 설명 텍스트 프리셋
- `BottomSheetModal.Action`: Primary/Secondary 버튼 영역(누르면 close 후 dismiss)
- `BottomSheetModal.Footer`: 하단 커스텀 영역

#### D-4. Backdrop / Background 커스터마이징

루트에서:
- `backdropComponent?: (props) => ReactElement | null`
- `backgroundComponent?: (props) => ReactElement | null`

을 통해 Gorhom 바텀시트의 backdrop/background를 커스터마이징할 수 있어요.

### (E) 내부 상태 / Shared Value / Animation (필수)

#### E-1. 상태 모델

`BottomSheetModal`은 내부적으로 아래 흐름으로 동작해요.

- 외부: `visible`(state)와 `onDismiss`(setter 역할)
- 내부: `useEffect`로 `visible` 변화에 따라 `present()` / `dismiss()` 호출
- 내부 컨텍스트: `InnerContext.close()`가 `onDismiss()`를 호출한 뒤 dismiss를 수행

즉, “닫기”는 내부적으로도 항상 `onDismiss()`를 통해 외부 상태를 내리는 걸 우선해요.

#### E-2. Reanimated / Shared Value

바텀 시트의 제스처/애니메이션은 주로 `@gorhom/bottom-sheet` 내부에서 처리돼요. 문서 관점에서는 다음을 권장해요.

- 프로젝트에 Reanimated/gesture-handler 설정이 정상 적용되어 있는지 확인
- 모달 내부에서 스크롤/제스처가 충돌하는 UI를 구성할 때(예: 가로 스와이프 + 바텀시트 드래그) 제스처 우선순위를 점검

---

### (F) 접근성(누락 금지)

`BottomSheetModal` 루트는 모달 스코프를 강조하기 위해 아래를 설정해요.

- `accessibilityViewIsModal`
- `importantForAccessibility="yes"`
- 내부 콘텐츠 컨테이너에도 `accessible` + `accessibilityViewIsModal`

권장사항:
- 닫기 버튼(또는 취소 액션)은 스크린리더 사용자에게 명확해야 하므로, `BottomSheetModal.Action`을 쓸 때 버튼 라벨을 명시해요.
- 아이콘만 있는 `actionIcon`을 사용하는 경우, 해당 아이콘 요소에 적절한 접근성 라벨을 제공해요.
