### (A) 한줄 요약

**`ImageCard`는 배경 이미지 위에 블러/그라데이션 오버레이를 얹고, 그 위에 텍스트/액션/푸터 슬롯을 배치하는 카드 컴포넌트예요.**  
`variant="vertical" | "horizontal"`로 콘텐츠 영역 방향을 선택하고, `aspectRatio`/`contentRatio`로 레이아웃 비율을 세밀하게 조정할 수 있어요.

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 가장 흔한 사용 시나리오(최소 예제)

```tsx title="ImageCard basic usage"
import { ImageCard } from '@fleet-ui/components';

export function Example() {
  return (
    <ImageCard
      source={{ uri: 'https://example.com/image.jpg' }}
      title="제목"
      description="설명"
      width={320}
      aspectRatio="16:9"
      accessibilityLabel="프로모션 카드"
    />
  );
}
```

#### D-2. 레이아웃: `variant` + `contentRatio`

- `variant="vertical"`: 콘텐츠가 하단에 위치(세로 카드)
- `variant="horizontal"`: 콘텐츠가 오른쪽에 위치(가로 카드)

`contentRatio`는 콘텐츠 오버레이(Front Layer)가 차지하는 비율이다.
- vertical: 높이 기준 비율(예: 0.34 → 하단 34%)
- horizontal: 너비 기준 비율(예: 0.44 → 우측 44%)

```tsx title="Horizontal variant with custom contentRatio"
import { ImageCard } from '@fleet-ui/components';

export function Example() {
  return (
    <ImageCard
      variant="horizontal"
      contentRatio={0.5}
      source={{ uri: 'https://example.com/image.jpg' }}
      title="가로 카드"
      width={360}
      aspectRatio={16 / 9}
    />
  );
}
```

#### D-3. 슬롯 구조(Top/Action/Footer)

- `topContent`: 이미지 상단에 absolute로 배치(배지/태그)
- `action`: 버튼/아이콘 등 액션 영역
- `footer`: 하단 푸터(통계/추가 액션)

### (E) 내부 상태 / Shared Value / Animation (필수)

`ImageCard`는 Reanimated shared value를 사용하지 않아요.  
대신 “3-layer 구조”를 내부에서 구성해 레이아웃을 만들어요.

- **Container Layer**: 외곽 프레임(패딩/보더/그림자/라운드)
- **Back Layer**: 배경 이미지(`expo-image`)
- **Front Layer**: 블러(`BlurView`) + 그라데이션(`LinearGradient`) + 콘텐츠 슬롯

또한 `aspectRatio`가 문자열인 경우 내부에서 파싱해요.

- `'width:height'` 형식만 지원(예: `'4:3'`, `'16:9'`)
- 파싱 실패 시 경고를 출력하고 기본 비율(1)로 폴백해요.

권장 규칙:
