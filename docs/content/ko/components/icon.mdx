### (A) 한줄 요약

**`Icon`은 `lucide-react-native` 아이콘을 Fleet UI 토큰(colorScheme/size)로 렌더링하는 래퍼 컴포넌트예요.**  
`icon`(컴포넌트 as prop) + `size/colorScheme`로 일관된 아이콘 스타일을 제공하고, `accessibilityLabel`로 접근성 트리에 의미를 전달해요.

---

### (B) 설치 방법 (Track A / Track B)

#### Track A (CLI / local install)

1) **Icon 추가**

```bash title="Track A: add Icon"
pnpm dlx @fleet-ui/cli add Icon
```

2) **import 예시**

```ts title="Track A: import"
import { Icon } from '@fleet-ui/local/components';
```

#### Track B (NPM package)

1) **import 예시**

```ts title="Track B: import"
import { Icon } from '@fleet-ui/components';
```

#### (필수) 컴포넌트별 추가 의존성

`Icon`은 `lucide-react-native` 아이콘 컴포넌트를 입력으로 받아요. 사용하려면 아래 의존성이 필요해요.

```bash title="Recommended deps"
pnpm add lucide-react-native
```

### (D) 핵심 기능(컴포넌트별) & 사용법

#### D-1. 가장 흔한 사용 시나리오(최소 예제)

```tsx title="Icon basic usage"
import { Icon } from '@fleet-ui/components';
import { Heart } from 'lucide-react-native';

export function Example() {
  return <Icon icon={Heart} accessibilityLabel="좋아요" />;
}
```

#### D-2. `colorScheme` vs `color`

- `colorScheme`는 테마 토큰에서 색상을 선택해요.
- `color`를 지정하면 **`colorScheme`보다 우선**해서 해당 색으로 렌더링해요.

```tsx title="Custom color overrides scheme"
import { Icon } from '@fleet-ui/components';
import { AlertTriangle } from 'lucide-react-native';

export function Example() {
  return (
    <>
      <Icon icon={AlertTriangle} colorScheme="warning" accessibilityLabel="경고" />
      <Icon icon={AlertTriangle} color="#FF00FF" accessibilityLabel="커스텀 색상 경고" />
    </>
  );
}
```

### (E) 내부 상태 / Shared Value / Animation (필수)

`Icon`은 내부 상태/애니메이션(shared value)을 갖지 않아요.

구현상 특징:
- `size`는 내부 `SIZE_MAP`으로 px 값으로 매핑돼요.
- 렌더링은 `View` 래퍼 안에 Lucide 아이콘 컴포넌트를 배치하는 형태예요.

### (F) 접근성(누락 금지)

권장 규칙:
- (웹) 키보드/포커스 이동이 자연스러운지 확인해요.
- (공통) 상태 변화가 스크린리더에 충분히 전달되는지 확인해요.

`Icon`은 기본적으로 `accessibilityRole="image"`로 렌더링되고, `accessibilityLabel`을 전달해요.

권장 규칙:
- **의미를 전달하는 아이콘**(상태/경고/의미 있는 버튼의 독립 요소)에는 `accessibilityLabel`을 제공해요.
- **순수 장식용 아이콘**(텍스트가 이미 의미를 전달)이라면, 상위 컴포넌트의 접근성 라벨/role에 포함되도록 구성하고 아이콘 자체는 스크린리더에 노출되지 않게 하는 패턴을 고려한다(예: 상위에서 라벨 제공).

> 참고: 현재 구현은 `accessibilityLabel`을 optional로 받지만, 문서/팀 규칙으로는 “의미 있는 아이콘이면 제공”을 강하게 권장해요.

### (G) Props Table (필수: 인터페이스 전체)

> 기준: `packages/components/src/Icon/Icon.types.ts`의 `IconProps`.  
> `IconProps`는 `ViewProps`를 상속해요.

| Prop | Type | Required | Default | Description | Platform notes |
| --- | --- | --- | --- | --- | --- |
| `icon` | `LucideIcon` | Yes | - | Lucide 아이콘 컴포넌트(Component as Prop) | `lucide-react-native` 필요 |
| `colorScheme` | `'primary' \| 'neutral' \| 'error' \| 'warning' \| 'success' \| 'info' \| 'secondary'` | No | `'neutral'` | 토큰 기반 색상 선택 | |
| `size` | `'_2xs' \| 'xs' \| 'sm' \| 'md' \| 'lg' \| 'xl' \| '_2xl' \| '_3xl' \| '_4xl'` | No | `'md'` | 아이콘 크기 프리셋 | 내부 SIZE_MAP으로 px 매핑 |
| `color` | `string` | No | - | 커스텀 색상(`colorScheme`보다 우선) | |
| `strokeWidth` | `number` | No | `2` | 선 두께 | |
| `accessibilityLabel` | `string` | No | - | 접근성 라벨(권장) | 의미 있는 아이콘이면 제공 권장 |

#### ViewProps 상속(요약)

`IconProps`는 `ViewProps`를 상속하므로 `style` 등 기본 props를 지원해요.
